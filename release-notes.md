# Web Console Release Notes

Web Console is a modern, browser-based Integrated Development Environment (IDE) embedded natively within Salesforce. It facilitates an in-context workflow for debugging, editing, and validating technical assets, removing the requirement for external tool integration or context-switching.

The Web Console provides a unified interface for the these development and administrative tasks:

- Native IDE Architecture: A fully featured, browser-resident development environment accessible directly within the Salesforce org.
- In-Context Editing: Accelerated modification capabilities for Apex code and workflows.
- Metadata Management: An integrated Org Browser for navigating system components.
- Advanced Data Querying: A Salesforce Object Query Language (SOQL) featuring an integrated Query Planner for performance optimization.
- Diagnostic Tools: A modernized execution log viewer and a comprehensive Apex testing suite.
- On-Demand Execution: Dedicated interface for Anonymous Apex code execution.

For more information about Web Console features and functionality, refer to the [Web Console developer documentation](https://developer.salesforce.com/docs/platform/webconsole/overview).

## April 14, 2026 (Open Beta)

Effective April 14, 2026, Web Console is available in open beta. Salesforce admins can provision access by enabling the Web Console via the Setup menu.
