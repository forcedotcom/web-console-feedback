# Build, Debug, and Deploy Directly in Salesforce

Web Console is a modern, lightweight, browser-based IDE built directly into Salesforce. Designed as a
seamless replacement for legacy tools, it offers a unified development workspace powered by VS Code for
Web without requiring local installations or complex setup.

## Developer Console Availability

**The Developer Console option is not visible by default in Setup**. 
To enable it, navigate to Setup, enter `Development` in the **Quick Find** box, and select **Web Console**. Switch the Enable Developer Console setting to Active. If Web Console is set to Inactive, Developer Console activates by default to restore standard setup buttons. If both environments are set to Active, both options remain available from the Setup menu. Refer to [Enable Web Console](https://developer.salesforce.com/docs/platform/webconsole/guide/enable-ide.html) for details.

## Key Highlights & Features

- Legacy Tool Modernization: Replaces aging environments like Developer Console and officially
unsupported tools like Workbench with a fast, modern interface.
- In-Org Apex & SOQL Execution: Write, test, and edit Apex code or run Salesforce Object Query
Language (SOQL) queries natively within your org.
- Zero-Setup IDE: Built on VS Code for Web, allowing pro-code and citizen developers to modify code
anywhere directly from the browser.
- Universal Access: Fully available and free across [all supported editions and environments](https://developer.salesforce.com/docs/platform/webconsole/guide/supported-orgs.html) — offering
an accessible alternative to paid tools like Agentforce Vibes IDE.
- Cost Efficiency: Empowers teams to perform quick direct modifications without relying on external
local tools or heavy custom templates.

For more information about Web Console features and functionality, refer to the [Web Console developer documentation](https://developer.salesforce.com/docs/platform/webconsole/overview).
