# Build, Debug, and Deploy Directly in Salesforce

:::note
Effective April 14, 2026, Web Console is available in open beta. Salesforce admins can provision access by enabling the Web Console via the Setup menu.
:::

Web Console is your modern, browser-based IDE built directly into Salesforce. Stop switching between tabs and external tools—stay in your flow and handle your entire workflow without leaving the platform.

## Take Control of Your Workflow
Access a native IDE directly within your Salesforce org for a seamless, browser-resident development experience.
Edit code in-context to rapidly modify Apex and workflows as you navigate.
Navigate system components with an integrated Org Browser to manage your metadata effortlessly.
Optimize data queries using the SOQL Builder and built-in Query Planner to ensure peak performance.
Diagnose issues faster with a modernized execution log viewer and a comprehensive Apex testing suite.
Execute code on-demand through a dedicated interface for Anonymous Apex.

For more information about Web Console features and functionality, refer to the [Web Console developer documentation](https://developer.salesforce.com/docs/platform/webconsole/overview).
