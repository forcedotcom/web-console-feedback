# Salesforce Web Console

Welcome to the next chapter of the Salesforce developer experience.

Curious about newer, modern Salesforce tooling, but not excited about installing and configuring everything locally? Want the convenience of the Developer Console with a more modern, browser-based experience? Looking for a feature-rich development environment that is integrated directly with Salesforce?

Meet **Salesforce Web Console**.

Salesforce Web Console is a lightweight, browser-based integrated development environment (IDE) built directly into your Salesforce org. It helps bridge the gap between the legacy Developer Console and the more resource-intensive Agentforce IDE, offering a fast, cost-effective experience for agile, in-context development workflows.

## About This Repository
